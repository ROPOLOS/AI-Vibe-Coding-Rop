# Teemo Bomber

A browser-based Bomberman-style arena game. [Play the live game](https://league-of-bomberman-teemos-revenge.vercel.app/).

## How to play

- Move with **WASD** or the **arrow keys**.
- Press **Space** to plant a mushroom bomb.
- Eliminate all four champions to win; avoid enemies and explosions.

## Run locally

Open `index.html` in a modern web browser. No build step or dependencies are required.
